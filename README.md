# 📚 Flashcard Simples para estudos

Um aplicativo web minimalista, rápido e direto ao ponto para criação e gestão de flashcards. Ideal para focar na memorização.

## ✨ Funcionalidades

* **Organização por Matérias:** Crie pastas específicas para separar seus estudos (ex: Direito Penal, Legislação Extravagante, Informática).
* **Cartões Interativos:** Cards com efeito 3D suave. A frente exibe a pergunta/conceito e o verso revela a resposta com um gradiente visual de "acerto".
* **100% Offline e Privado:** Não precisa de banco de dados. Tudo é salvo diretamente no `localStorage` do seu navegador.
* **Backup de Dados:** Funcionalidade de **Exportar** e **Importar** seus flashcards no formato `.json` para garantir que você nunca perca seus resumos.
* **Design Moderno:** Interface limpa construída com a tipografia *Poppins* e paleta de cores focada em reduzir o cansaço visual durante longas horas de estudo.

## 🚀 Como Executar o Projeto

Como o projeto não utiliza banco de dados ou frameworks complexos, rodar ele é extremamente simples:

1. Faça o download ou clone este repositório.
2. Dê um duplo clique no arquivo `index.html`.
3. Ele abrirá automaticamente no seu navegador padrão (Chrome, Edge, Firefox, etc.) pronto para uso.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** Estilização moderna (Glassmorphism sutil, transições 3D, variáveis CSS).
* **JavaScript (Vanilla):** Lógica de criação, exclusão, virada de cartas e manipulação do armazenamento local, sem dependência de bibliotecas externas.

## 💡 Casos de Uso (Exemplo prático)

1. Crie uma pasta chamada **"Direito Constitucional"**.
2. Adicione um novo flashcard.
    * **Frente:** *Quais são os fundamentos da República? (Art. 1º)*
    * **Verso:** *So Ci Di Va Plu (Soberania, Cidadania, Dignidade, Valores sociais, Pluralismo).*
3. Faça suas revisões diárias clicando nos cards para revelar a resposta!
